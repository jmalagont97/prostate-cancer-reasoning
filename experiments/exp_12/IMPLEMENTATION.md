## 3. Subtask 2.1 — Treatment Recommendation (4-class)

### 3.1 Conditions (frozen from exp_10 — no re-selection)

| Condition | Family | Config (from exp_10 best_hyperparams.json) | Fusion weights |
| :--- | :--- | :--- | :--- |
| C1 | Fuzzy (H2) | tab k=1, mri k=5, txt k=5; uniform; txt max_features=None | (0.35, 0.45, 0.20) |
| C2 | Hard (H1) | tab k=1, mri k=5, txt k=3; uniform; txt max_features=500 | (0.35, 0.45, 0.20) |

### 3.2 Pipeline
- Load `best_hyperparams.json` from exp_10 results; instantiate MulticlassKNN(n_classes=4).
- For each of 100 splits: fit preprocessors on train, compute per-modal probs, fuse with frozen weights, argmax to 4-class.
- LOOCV (Phase B): same frozen configs, retrain on 69, predict 1.

## 4. Subtask 2.2 — Clinical Confidence (3-class ordinal)

### 4.1 Targets
- GT: `confidence` from reasoning JSON (clear=56, borderline=14, uncertain=0).
- Soft-targets ordinal: `clear=1.0`, `borderline=0.5`, `uncertain=0.25` (exp_6-style, NOT the 0.25+0.75c formula).
- Hard: one-hot 3-class.

### 4.2 Conditions

| Condition | Modality | Grid |
| :--- | :--- | :--- |
| C3 | Tabular fuzzy | k in {1,3,5,7} x weights {uniform,distance} |
| C4 | MRI fuzzy | k in {1,3,5} x weights {uniform,distance} |
| C5 | Text fuzzy | k in {1,3,5} x max_features {500,None} |
| C6 | **Fusion** | soft-voting w in Delta^2 (step 0.05, 231) — grid search within 2.2 (not frozen) |

### 4.3 Metrics
- Primary: `compute_confidence_score` (ordinal distance), Macro-F1 (3-class).
- Secondary: Brier multiclass, per-class F1 (clear/borderline/uncertain), MOE_abs (exp_6-style).
- **Pre-registered caveat**: `uncertain` (n=0) cannot be learned; per-class F1 for that class will be 0/undefined. Report ordinal distance + Brier as honest primary.

## 5. Subtask 2.3 — Variable Weights (11 vars x 4 ordinal levels)

### 5.1 Targets
- GT: `variable_weights` dict (11 vars). Missing vars in GT = implicit `not_used` (class 0).
- Ordinal: not_used=0, noted=1/3, important=2/3, decisive=1.0 (soft regression targets).
- Per-variable class labels for classification (RF/ExtraTrees): not_used=0, noted=1, important=2, decisive=3.

### 5.2 Feature space for meta-models
- Concatenate per split (train-only fits): tabular 32D + MRI-PCA-16 + TF-IDF top-k (k=50 for tractability) = ~98D joint space.
- Optional: raw feature + attribution augmentation (exp_9-style 23D) if performance low — pre-registered fallback.

### 5.3 Conditions

| Condition | Algorithm | Per-variable | Class handling |
| :--- | :--- | :--- | :--- |
| C7 | RandomForestClassifier | 11 independent models (one per var) | class_weight='balanced' |
| C8 | ExtraTreesClassifier | 11 independent models | class_weight='balanced' |
| C9 | **Best per-variable selection** | Pick by mean val Macro-F1 over 100 splits | — |

### 5.4 Metrics
- Primary: `compute_variable_weights_score` (mean inverse normalized MAE), `compute_important_decisive_f1` (Set-F1 over {important, decisive}).
- Secondary: per-variable Spearman rho vs GT ordinal (with p-values), per-variable Macro-F1.

## 7. Statistical Tests

1. Wilcoxon paired (alpha=0.05) 2.1: C1 vs C2 (100 splits).
2. Wilcoxon paired exp_12-2.1 vs exp_10-H2 (cross: shared 100 splits, load exp_10 split_metrics.json).
3. Descriptive comparison 2.2 vs exp_6 (Task-1) — split misalignment prevents paired test.
4. Per-variable Spearman rho (2.3) with p-values vs null rho=0; Bonferroni correction (alpha/11).

## 8. Model Persistence (Pickles)

Per DESIGN.md section 7.2 — `save_best_models.py`:

### 8.1 Subtask 2.1
- Retrain fuzzy-KNN (frozen configs) on ALL N=70, save `{preprocessor_tab, preprocessor_mri, preprocessor_txt, models: {tab, mri, txt}, fusion_weights}` to `subtask1_treatment_fuzzy_knn.pkl`.

### 8.2 Subtask 2.2
- Retrain best fuzzy-KNN per modality (from Phase A of 2.2) + best fusion on ALL N=70, save same structure to `subtask2_confidence_fuzzy_knn.pkl`.

### 8.3 Subtask 2.3
- Retrain best algorithm per variable (C9 selection) on ALL N=70, save `{models: {var: trained_estimator}, preprocessors, ordinal_map}` to `subtask3_weights_ensemble.pkl`.

All pickles use the `sys.modules['__main__']` loading trick (validated in exp_10/11).

## 9. Inference Script (predict_case_task2.py)

- Accepts a case directory (structured-prompt.json, clinical-data.json, neural-representations.json).
- Loads the 3 pickle bundles.
- Produces the two official Task-2 outputs per case:
  1. `prostate-treatment-decision.json` — 4-class string (from subtask 2.1).
  2. `prostate-treatment-decision-reasoning.json` — `{confidence, variable_weights (11), reveal_sequence, free_text}` (from subtasks 2.2 and 2.3, reveal_sequence=[] , free_text auto-generated).
- Returns both dicts (and writes to disk if output_dir provided).
