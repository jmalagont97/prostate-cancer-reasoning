## 4. Subtask 2.1 (Treatment, 4-class)

| Cond | Description | Config |
| :--- | :--- | :--- |
| C1 | **Frozen exp_10 H2 fuzzy-KNN** (isolates pure feature effect) | k_tab=1, k_mri=5, k_txt=5, uniform; fusion w=(0.35, 0.45, 0.20) — from exp_10 best_hyperparams.json |
| C2 | **Re-grid on 29-col space** (exploratory best achievable) | k in {1,3,5,7} per modality; fusion search Delta^2 |

Pipeline per condition: fit preprocessors on train fold, per-modal fuzzy-KNN probs, weighted fusion, argmax to 4-class.

## 8. Metric Computation & Statistical Tests

| Subtask | Official gate | Homologated |
| :--- | :--- | :--- |
| 2.1 | compute_treatment_decision_gate | Macro/Micro/Weighted-F1, AUROC, Brier |
| 2.2 | compute_confidence_score | Macro-F1, Brier |
| 2.3 | compute_variable_weights_score, compute_important_decisive_f1 | per-var Spearman rho, per-var Macro-F1 |

Tests:
1. Wilcoxon paired exp_14-2.1-C1 vs exp_12-2.1-C1 (same frozen config; feature-only difference).
2. Wilcoxon paired exp_14-2.1-C2 vs exp_12-2.1-C1 (best-ablated vs frozen-full).
3. Wilcoxon paired exp_14-2.2 vs exp_12-2.2 (Brier / Macro-F1).
4. Descriptive 2.3 per-variable deltas.
5. McNemar exact if Wilcoxon marginal (p in [0.05, 0.10]).
