## 3. Feature Injection (nested cross-fitting — mandatory leakage guard)

### 3.1 Source 2.1 model (frozen from exp_11)

Config from `experiments/exp_11/results/best_hyperparams.json` key `fuzzy`:
- tabular: C=0.1, epsilon=0.05
- mri: C=0.1, epsilon=0.1
- text: C=10.0, epsilon=0.05, max_features=None
- fusion weights: (0.55, 0.20, 0.25)

### 3.2 Injection representations

| Cond | Representation | Dimensionality |
| :--- | :--- | :---: |
| C0 | none | 0 |
| C1 | probability vector = SoftLinearSVR 4-class outputs (L1-normalized) | +4 |
| C2 | argmax one-hot over 4 classes | +4 |
| C3 | concat(probability vector, argmax one-hot) | +8 |

### 3.3 Nested OOF procedure (per MCCV split)

For every MCCV split (100 total):
1. Train 2.1 frozen fuzzy-SVR on the train fold (69-ish cases).
2. Compute **train-case 2.1 outputs** by **5-fold inner CV** inside the train fold: partition train into 5, fit 2.1 on 4 parts, predict the held-out part, concatenate → OOF vectors. (Prevents self-prediction leakage.)
3. Compute **val-case 2.1 outputs** by predicting the val fold with the full 2.1 model from step 1.
4. Build the injected tabular feature matrix by appending the chosen representation to the original tabular branch.
5. Train 2.2 (SoftLinearSVR per modality + late fusion) using the OOF train representations.
6. Predict val 2.2 using stride-3 representations.

The injection is appended ONLY to the tabular branch.

## 4. Subtask 2.2 Model & Targets

- **Family**: Soft-SVR (best 2.2 family in exp_13) per modality.
- **Fusion**: late soft-voting over Delta^2 (step 0.05, 231 weights); weights re-searched inside each condition (because the input space changed).
- **Targets (Choice 3 = C)**:
  1. 3-class: `uncertain`=0, `borderline`=1, `clear`=2 (soft targets ordinal clear=1.0, borderline=0.5, uncertain=0.25).
  2. binary: `borderline`=0, `clear`=1 (drop uncertain examples; n=70 remains because uncertain n=0).

## 5. Confusion Matrices (REQUIRED by DESIGN 5.1)

For EVERY condition (C0, C1, C2, C3) and EVERY target (3-class, binary):

### 5.1 Matrix construction
- rows = ground truth, columns = predicted, integer counts.
- labels:
  - 3-class: [uncertain, borderline, clear] (3x3)
  - binary: [borderline, clear] (2x2)

### 5.2 Aggregation levels
1. **MCCV_aggregated**: sum of the 100 val-fold confusion matrices (total N ≈ 2100 per condition/target).
2. **LOOCV**: sum of the 70 leave-one-out predictions.

### 5.3 Persistence
`confusion_matrices.json`:
```
{
  "C0": {"3class": {"mccv": [[..]], "loocv": [[..]]}, "binary": {"mccv": [[..]], "loocv": [[..]]}},
  ...
}
```

## 6. Metrics & Statistical Tests

| Target | Primary | Secondary | Gate |
| :--- | :--- | :--- | :--- |
| 3-class | Macro-F1, Brier | S_conf (ordinal), per-class F1 | compute_confidence_score |
| binary | Macro-F1, Brier | precision/recall per class | (binary confidence score) |

Tests:
1. Wilcoxon paired C1/C2/C3 vs C0 — 3-class Macro-F1 and binary Macro-F1 (100 splits).
2. Wilcoxon paired C1 vs C2 (probs vs argmax) — tests H2.
3. McNemar exact on the aggregated binary 2x2 (MCCV) for C_i vs C0, if Wilcoxon marginal.
4. LOOCV accuracy reported per condition.
