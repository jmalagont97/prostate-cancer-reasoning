## 3. Subtask 2.1 — Treatment (4-class, FROZEN exp_11 configs)

### 3.1 Conditions

| Cond | Family | Config (from exp_11 best_hyperparams.json) | Fusion |
| :--- | :--- | :--- | :--- |
| C1 | Fuzzy-SVR | tab C=0.1 eps=0.05; mri C=0.1 eps=0.1; txt C=10 eps=0.05 full vocab | (0.55, 0.20, 0.25) |
| C2 | Hard-SVC | tab C=0.1; mri C=0.1; txt C=10 max_features=500 | (0.85, 0.15, 0.00) |

### 3.2 Pipeline
- Load exp_11 best_hyperparams.json; instantiate HardLinearSVM / SoftLinearSVR(4-class).
- Phase A: 100 splits — fit preprocessors on train, per-modal Platt/regression probabilities, fuse, argmax.
- Phase B: frozen LOOCV (69 train, 1 val) for both C1 and C2.

---

## 4. Subtask 2.2 — Confidence (3-class ordinal + binary secondary)

### 4.1 Targets
- GT confidence: clear=56, borderline=14, uncertain=0.
- Ordinal soft targets: clear=1.0, borderline=0.5, uncertain=0.25 (identical exp_12 mapping).
- Binary secondary (C6): drop uncertain examples (zero anyway) -> clear vs borderline (2-class).

### 4.2 Conditions

| Cond | Family | Grid |
| :--- | :--- | :--- |
| C3 | Hard SVC 3-class | C in {0.1, 1.0, 10.0} x class_weight {None, 'balanced'} per modality |
| C4 | Soft SVR ordinal | C in {0.1, 1.0, 10.0} x epsilon {0.05, 0.1} per modality |
| C5 | **Fusion** | soft-voting w in Delta^2 (step 0.05, 231 weights) per family |
| C6 | **Binary clear-vs-borderline** | SVC/SVR on 2 classes (clear/borderline), per family |

### 4.3 Metrics
- Primary: Brier (3-class), ordinal S_conf via `compute_confidence_score`.
- Secondary: Macro-F1 3-class, Macro-F1 binary (C6), per-class F1.
- Pre-registered: `uncertain` never predicted (SVM rigid margin + n=0); report as structural limitation.

---

## 5. Subtask 2.3 — Variable Weights (11 vars x 4 ordinal)

### 5.1 Targets
- GT variable_weights with omissions = implicit not_used (audited 18/70 for bx_*).
- Ordinal soft targets: not_used=0, noted=1/3, important=2/3, decisive=1.0.
- Class labels: not_used=0, noted=1, important=2, decisive=3.

### 5.2 Feature space (28+16+50D joint — same as exp_12)
- Tabular 32D (StandardScaler) + MRI-PCA-16 + TF-IDF-50 = ~98D per split.

### 5.3 Conditions

| Cond | Algorithm | Per-variable | Handling |
| :--- | :--- | :--- | :--- |
| C7 | SVC(linear, probability=True) | 11 models | class_weight='balanced', 4-class |
| C8 | MultiOutputRegressor(LinearSVR) | 11 models | 4-soft ordinal targets |
| C9 | **Best per-variable C7 vs C8** | by mean val Macro-F1 | |

### 5.4 Metrics
- Primary: `compute_variable_weights_score`, `compute_important_decisive_f1`.
- Secondary: per-variable Spearman rho + Bonferroni (alpha/11), per-variable Macro-F1.
- Pre-registered fallback: exp_8/9-style SHAP-attribution augmentation if C7/C8 underperform (pirads target < 0.30).

## 6. Phase B LOOCV (INCLUDED — closes exp_12 protocol gap)

- For every holdout case (70 folds): retrain preprocessors + SVM on 69, predict 1.
- Applies to all three subtasks with frozen Phase-A hyperparameters.
- Persist LOOCV metrics in aggregate_metrics.json under `loocv_` per condition.

## 8. Statistical Tests

1. Wilcoxon paired 2.1: C1 vs C2 (100 splits) + exp_13-2.1 vs exp_11-H2 (cross).
2. Wilcoxon paired 2.2: exp_13 (SVM) vs exp_12 (KNN) on 3-class Brier and binary Macro-F1.
3. Per-variable Spearman rho (2.3) vs null rho=0, Bonferroni alpha/11.
4. McNemar exact 4x4 only if Wilcoxon marginal (p in [0.05, 0.10]).
